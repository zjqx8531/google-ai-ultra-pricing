## 两档 Ultra 的真实差别

$100 档拿到的是：Gemini 应用和 Google Antigravity 里 5 倍于 Pro 的用量、Gemini 3.5 Flash 集成、Antigravity 的优先访问权、20TB 云存储、YouTube Premium 个人版 [1][3][13]。

还有一个容易被忽略的减法：Ultra 的存储上限从原来的 30TB 调整为 20TB [6][8][11]。也就是说 Ultra 变便宜的同时，存储缩水了。PCMag 的报道把最高档写成 30TB [5]，跟多数报道不一致，这种地方不要信二手信息，结账页写什么就是什么。

差价值不值？ZDNET 的判断挺直白：如果你在做开发或专业工作，便宜那档更可能是合适的起点，真撞到用量上限再往上换 [9]。$100 到 $200 之间翻倍的钱，主要买的是 20 倍用量和 Project Genie。Project Genie 是个研究原型，不是日常生产力工具，为了它单独上 $200 档，理由不太够。

## 计费方式也一起改了

这轮调整里比价格更重要的一件事：Gemini 不再按「每天能问多少次」计费，改成按算力计量，会综合考虑提示词复杂程度、调用的功能和对话长度，额度每 5 小时刷新一次，直到撞上每周上限 [9][12]。超限之后系统会自动把你从大模型切到小模型；Pro 和 Ultra 用户可以另外买加量包，用在 Antigravity、Google Flow，以及后续上线的 Gemini 应用上 [12][1]。

如果你以前抱怨过「才问了几次就限流」，新规则理论上更宽容；但反过来说，长对话和重任务会更费额度，靠刷短提示词薅额度的玩法行不通了。

## 几个高频问题

**上传 Session 安全吗？**
Session 本质是浏览器的登录凭据。平台拿到它，就能以你的身份进入账号、完成订阅操作 [17]。它不涉及账号密码，但「平台能进你账号」这件事是事实，风险不等于零。用一个你不在别处复用的干净账号，会稳妥一些。

**订阅是上游一次性支付整段周期吗？**
不是。你先一次性把钱付给平台，上游仍然是按月扣款、按月开通，剩下的月份由平台继续替你处理 [17][19]。

**出问题能退款吗？**
从记录看，能。上面两个案例分别拿到了 $22 的比例退款和 ¥150.69 的退款 [18][19]。但退款依赖客服响应，有人遇到过客服不回 [20]。
